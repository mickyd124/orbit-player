# Orbit Player for LG webOS

Orbit Player v1.0.0 is a remote-friendly LG webOS 6+ media player with HTTP(S), HLS and DASH playback, local-file support where available, and an optional LAN companion for FFmpeg conversion and BitTorrent magnets.

The source and GitHub Actions deployment are being initialized from the uploaded Orbit Player project. Physical TV compatibility must be verified on the device.
